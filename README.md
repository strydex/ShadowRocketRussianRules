Этот репозиторий содержит оптимизированный конфигурационный файл `.conf` для приложения **Shadowrocket** (iOS). Конфигурация настроена для гибкой маршрутизации трафика, блокировки рекламы и улучшения скорости соединения.

> **Автор:** Эмир (Viper Labs)  
> **Web:** [Веб-Портфолио](https://strydex.is-a.dev)

## ✨ Возможности
- 🎯 **Умная маршрутизация:** Автоматическое разделение трафика (Global/Rule/Direct).
- 🛡 **Блокировка рекламы:** Правила для фильтрации назойливых баннеров и трекеров.
- ⚡ **Оптимизация:** Улучшенные правила для стабильного соединения.
- 👾 **Предотвращение утечки DNS:** Использование профиля от Xbox-DNS для правильного проксирования "Умных DNS".

## 📥 Как установить

Выберите один из двух способов установки конфигурации.

### Способ 1: Установка по ссылке (Рекомендуется)
Этот способ позволит вам легко обновлять конфиг в будущем.

1. Скопируйте ссылку на raw-файл `.conf` (нажмите на файл в репозитории -> кнопку `Raw` -> скопируйте URL).
   > *Пример ссылки:* `https://raw.githubusercontent.com//strydex/ShadowRocketRussianRules/main/stryconf.conf`
2. Откройте **Shadowrocket**.
3. Перейдите во вкладку **Config** (Конфигурация) в нижнем меню.
4. Нажмите **+** (плюс) в правом верхнем углу.
5. Вставьте скопированную ссылку в поле URL и нажмите **Download** (Скачать).

### Способ 2: Установка файлом
Если вы скачали файл `stryconf.conf` на устройство.

1. Скачайте файл `.conf` из этого репозитория.
2. Откройте приложение **Файлы** на iPhone, найдите скачанный файл.
3. Нажмите кнопку **Поделиться** (Share) -> выберите иконку **Shadowrocket**.
   *(Или в самом Shadowrocket: Config -> Import from Cloud/Wi-Fi Upload)*.

## ✅ Как применить конфигурацию

После импорта (по ссылке или файлом) выполните следующие шаги для активации:

1. В приложении перейдите во вкладку **Config**.
2. Найдите в списке (раздел *Local Files* или *Remote Files*) файл `shadowrocket.conf`.
3. Нажмите на название файла.
4. В появившемся меню выберите **Use Config** (Использовать конфигурацию).
   > 🟢 После этого напротив файла должна появиться галочка или оранжевый кружок.
5. Перейдите на вкладку **Home** и убедитесь, что в поле *Global Routing* выбрано **Config**.

## 🔐 Установка сертификата DNS (Опционально, необязательно!)
Для корректной работы ChatGPT, Gemini, Framer, GitHub Copilot, Notion, Framer необходимо дополнительно установить системный сертификат DNS-over-HTTPS на iOS.

1. Откройте эту страницу Github на **айфоне**.
2. Нажмите на [**Ссылку**](https://xbox-dns.ru/ios/xbox-dns.mobileconfig).
3. Разрешите загрузку, затем откройте **«Настройки»**. Наверху появится меню **«Профиль загружен»**.
4. Выберите скачанный профиль и нажмите **«Установить»** в правом верхнем углу, следуя инструкциям на экране.

## 🔄 Как обновлять
Если вы установили конфиг **по Способу 1**, для обновления просто свайпните (потяните) влево по названию конфига во вкладке Config и нажмите **Update**.
